# 猜股票 E-I 实施状态

## 已完成并通过阶段自检

### 迭代 E

- AI 公共决策快照不再读取真人当前待成交订单。
- Prompt 不再包含精确事件当前冲击、剩余冲击或私有未来切片。
- 旧观点的事件残余条件只读取公开档位。
- 波动状态改为实现波动归一化，并增加逐级降温。
- 价格审计新增原始合计和限幅修正，regime 不再承载限幅残差。
- 事件候选支持相对权重，编辑器和 CSV 支持配置。
- 完整 10,000 局校准通过；FULL_MARKET 波动分布为 LOW 32.01%、NORMAL 51.40%、HIGH 15.69%、EXTREME 0.90%。

## 已实现的后续功能

### 迭代 F

- 新增复用 V2 市场状态、价格和目标仓位执行器的配对种子对抗模拟器。
- 包含现金、买入持有、定投、事件、均值回归、趋势和 Thesis 七种策略。
- 新增集中式 AI 难度能力策略，生产 Prompt 按难度使用 6/20/50 回合公开历史。
- AI 任务增加供应商、模型、模型耗时、Token、HTTP 状态、请求次数、缓存和降级遥测。
- 增加按场次调用次数、Token 和失败数计算的模型预算，超限后自动沿用观点或本地策略。
- 5,000 个共享市场种子的难度联赛已进入测试与完整校准报告；当前 Normal 对 Easy 为 59.33%，Hard 对 Normal 为 48.64%。

### 迭代 G

- 新局支持 `INLINE` 融资，借款直接在开盘交易阶段完成，不再固定插入贷款阶段。
- 增加快速、标准、长线、高波动和信用危机场景预设。
- 当前阶段 AI 决策在结算前不再返回客户端。
- INLINE 模式仅在贷款到期、风险达到 WARNING 以上或最终回合进入专门还贷节点。
- 游玩页增加已结算市场、AI、本人交易和贷款流水时间线，以及 V2/V3 价格分解。

### 迭代 H

- 新增价格引擎 V3，包含需求、订单、库存、利润率和现金流五项基本面。
- 有效事件会按类型和方向改变公司基本面，基本面锚和财报预期差以有限幅度进入价格。
- 定期财报只在指定回合公开精确指标，其他回合不会通过行情 API 泄漏内部指标。
- 财报以幂等方式写入独立财报表，记录市场预期区间、基本面和预期差。
- 事件链状态可持久化、限制深度并以概率触发后续事件。
- 事件链字段已经接入 Web 编辑器和 CSV 导入导出。
- 真人研究点、幂等研究 API 和 Web 研究面板已经接通，结果为带误差区间；AI 可输出 `research_action`，使用同一预算并在后续决策中读取自己的研究结果。

### 迭代 I

- 完成与提交顺序无关的目标仓位统一竞价引擎、正式目标仓位下单、开收盘结算、强平联动、部分成交、手续费与滑点对账。
- Web 创建页、游戏详情、规则说明和交易面板均已支持 `TARGET_AUCTION`；竞价截止前不再公开其他参与者的密封目标。
- 完成每日挑战固定种子及风险徽章计算引擎。
- 每日挑战已接通固定种子场次、幂等成绩提交、风险指标、研究准确率、Top 100 API、独立排行榜页、创建页开关和 Web 入口。
- 局末已增加 AI 最佳决策、最大错误、换观点、反向交易、模型调用/降级、利息与强平复盘。
- 已提供 V46-V50 数据库结构和对应回滚脚本。

## 尚未完成

- F：生产模拟器尚未接入内存信用账本和四个信用纯引擎；Hard 对 Normal 的风险调整胜率当前 48.64%，未达到 55% 验收线；真实模型 trace replay 和 50～200 局付费 profile 未完成。
- G：时间线尚未合并延期、观点证据展开等全部细节；未做完整多人手机端人工流程验收。
- H：缺少完整 V3 10,000 局方向、财报预期和事件链恢复校准；财报历史尚无单独列表页。
- I：赛季、跨日总榜和持久化成就系统未实现；竞价暂未提供逐笔盘口，因为该模式采用密封统一清算而非连续订单簿。
- 发布：V41-V50 尚未在真实 MySQL 备份库执行完整迁移/回滚演练，也未进行 TARGET_AUCTION 多人浏览器端到端压力测试。

## 本轮验证

- 新增竞价现金约束、流动性分配和研究准确率测试；定向测试全部通过。
- 完整市场校准：6 场景、V1/V2 各 10,000 局通过，报告位于 `backend/target/guess-stock-calibration/report.json`。
- Web 生产构建：1916 个模块通过。
- 后端全量测试：263 个测试中 0 failure、8 error；8 个 error 均来自本机 `127.0.0.1:6379` 未运行的 `RedisConnectionTest`，其余测试通过。
