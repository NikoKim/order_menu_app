# 聊天与通知 V2 实施计划

1. 扩展数据库迁移、实体、DTO 与消息接口，先补充失败测试，再实现引用、撤回、用户侧删除及中文错误信息。
2. 完成家庭群聊待加入、拒绝、加入审核、审批和加入/退出系统消息，并覆盖服务测试。
3. 修正菜品分享约束，保存店铺名称快照，并支持从菜品卡片跳转店铺与置顶“刚刚浏览”。
4. 改造顾客端聊天列表与详情：顶部实时用户搜索、头像徽标、群聊标签、用户资料、引用/撤回/删除、时间格式和自动滚动。
5. 改造商家端聊天列表与详情：移除发起聊天入口、统一气泡、群资料编辑、成员头像/中文状态、聊天设置页。
6. 统一两端通知入口、底栏和快捷应用徽标，修复商家通知位置与加载逻辑。
7. 引入中央覆盖式中文提示组件并替换本轮相关页面提示，检查页面在主页框架下的响应式布局。
8. 运行后端、顾客端和商家端全量测试与静态分析，修复回归并记录未实现的第 16 项。
