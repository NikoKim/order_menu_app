# Naval Chat Stickers

Original bitmap art generated with the built-in image generation tool, then
chroma-keyed, split and nearest-neighbor scaled with `generate2dsprite`.
Transparent PNGs are 256 x 256. Runtime renders messages from a fixed ID
allowlist, never a user-supplied image URL.

## Delivered Assets

| ID | Meaning |
| --- | --- |
| salute | Happy captain battleship, greeting and salute |
| surprised | Startled submarine, discovered or surprised |
| heart | Radio console sending a heart, appreciation |
| surrender | Singed battleship and white flag, surrender |
| sleepy | Sleepy nightcap battleship, waiting |
| applause | Clapping radar console, well played |
| challenge | Confident submarine, challenge accepted |
| reconnect | Worried unplugged radio, connection lost |

## Art Prompts

Pack 1: Exact 2 x 2 equal-cell sprite pack on solid magenta. Original crisp
16-bit pixel art, navy outlines, teal, ivory, coral and gold palette. Four
expressive anthropomorphic naval hardware reactions: cheerful captain
battleship saluting, startled submarine in a splash, friendly radio sending
a heart, comically singed battleship surrendering. Large readable stickers,
consistent scale, no text, no labels, transparent final cutouts.

Pack 2 (accepted revision): Exact 2 x 2 equal-cell pack on solid magenta.
Keep every subject and prop within the central 60 percent of its square,
with wide empty gutters. Compact rounded silhouettes and crisp chunky
16-bit shading. Sleepy battleship with starry nightcap and small moon;
cheerful golden radar clapping white gloves; confident teal submarine with
small raised fists and an upright coral pennant; worried ivory radio holding
a short unplugged cable. No long projectiles, no labels, no text.
