# Naval sound library

Original offline-designed stereo PCM WAV effects. No third-party samples or external licensing dependencies. Generated by `node scripts/build-naval-audio.mjs` from the frontend folder.

44.1 kHz, stereo, 16-bit PCM. Layers include filtered impact textures, sub-bass transients, resonant metal, propeller passes, water droplets and decorrelated stereo reflections. Runtime uses decoded sample playback, not live oscillator synthesis.
